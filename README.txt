Midoré Matcha POS

Included:
- Responsive browser POS for PC, cellphone, and iPad
- Menu preloaded from the supplied Midoré Matcha menu
- Cart, quantity controls, cash/change calculation
- Printable receipts
- Sales history and daily sales summary
- Product add/delete
- Local storage (data is saved in the browser/device)
- PWA manifest/service worker for installable app behavior

Quick start:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For installation as a PWA and offline support, serve the folder from a local web server or web hosting (service workers normally require HTTPS or localhost).
4. On iPhone/iPad Safari, use Share > Add to Home Screen after hosting it.
5. On Android Chrome, use the browser's Install/Add to Home screen option.
